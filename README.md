# 植生野帳（Vegetation Relevé Notebook）

Braun-Blanquet法（植物社会学的手法）による植生調査を、**現場での記録から植生表・群落区分・遷移予測・現存植生図の作成まで**ひとつのアプリで行うWebアプリ（PWA）です。GitHub Pagesで公開すれば、スマートフォンにインストールして**圏外でも**使えます。データは**Excelファイル**で書き出し・読み込みできます。

## 主な機能

| 段階 | 内容 |
|---|---|
| プロジェクト | 調査地域・年度ごとにプロジェクトを作成し、スタート画面から開く。名前の変更、Excelへの書き出し、削除（確認つき） |
| 記録 | 調査区の環境情報、5階層の高さ・植被率、出現種の被度・群度。入力中は下書きとして自動で残り、「この調査を保存」で確定 |
| 削除 | 調査区・出現種・植生区画・プロジェクトの削除は、すべて確認のうえ実行（プロジェクトは名前の入力も必要） |
| 植生表 | 素表、区分表（UPGMA＋φ係数による識別種）、常在度表、樹形図 |
| 群集の判定 | 都道府県・標高から植生帯と日本海側／太平洋側を推定し、地域の群集と照合。「算出の内訳」で種ごとの寄与と係数を表示 |
| 遷移予測 | 管理シナリオと年数に応じた到達植生。「算出の内訳」で使った年数と補正係数を表示 |
| 植生図 | 地理院地図上で調査区を色分けし、植生区画を描画 |
| 根拠と出典 | 各計算が「確立した方法」「慣行」「本アプリ独自の目安」のどれかを示し、文献を掲載 |

## 公開方法（GitHub Pages、スマホのみで可）

ファイルはすべて同じ階層にあり、フォルダはありません。

1. ブラウザで github.com を開き、新しいリポジトリを作ります（Public、「Add a README file」にチェック）。
2. 「Add file → Upload files」で次の7ファイルをまとめて選び、「Commit changes」を押します。
   `index.html` `sw.js` `manifest.webmanifest` `icon-192.png` `icon-512.png` `icon-maskable-512.png` `LICENSE`
   （README.md も上書きしてかまいません）
3. 「Settings → Pages」で Branch を `main`、フォルダを `/ (root)` にして「Save」。
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。

「Upload files」が見つからない場合は、ブラウザのメニューで「PCサイトを表示」に切り替えてください。**更新するとき**は、変更したファイルを同じ名前でアップロードし直すと上書きされます。

## Excelでの管理

- **書き出し**：プロジェクト画面または調査区一覧の「Excelに書き出す」。1ファイルに次のシートが入ります。
  - 読み込みにも使うシート：説明、調査区、出現種、植生区画、群集参照DB、遷移年数、植生帯境界、判定パラメータ
  - 解析結果（書き出しのみ）：素表、区分表、常在度表、群集判定、遷移予測
- **1地点だけ**：記録画面の「Excelに書き出す」で、その調査区だけのファイルを作れます。
- **読み込み**：プロジェクト画面の「Excelから読み込む」で新しいプロジェクトとして、調査区一覧の「Excelから追加」で開いているプロジェクトへ追加します。同じ調査区番号があるときは、上書きするかを確認します。
- **記入用テンプレート**：同梱の「植生野帳_記入用テンプレート.xlsx」は選択リスト付きです（アプリ内のテンプレートボタンでも作れますが、選択リストは付きません）。
- 地域の群集を加えるときは、書き出したファイルの「群集参照DB」シートに行を足し、出典区分を「追加」にして読み込みます。遷移年数・植生帯境界・判定の重みも、各シートを編集して読み込むと計算に反映されます。

## オフラインで使うには

- 出発前に一度オンラインでアプリを開き、「ホーム画面に追加」をしてください。アプリ本体、地図ライブラリ、Excelライブラリが端末に保存されます。
- 背景地図は、オンライン時に表示した範囲のタイルだけが保存されます。
- 通信が必要なのは、標高・都道府県の自動取得と、未表示範囲の地図タイルだけです。GPSは圏外でも使えます。

## データの保存

データは端末のブラウザ内に保存されます。ブラウザのデータ消去やアプリの削除で失われるため、**調査のたびにExcelへ書き出して保管**してください。機種変更時は「設定 → その他の形式」の全プロジェクトのバックアップも使えます。

## 計算の根拠

アプリ内の「根拠と出典」画面（設定画面・判定画面からリンク）に、算出式・係数・文献をまとめています。群集の適合度（%）は本アプリ独自の目安で、確率ではありません。遷移の年数と補正係数も本アプリの目安で、地域のデータで校正することを推奨します。文献の書誌情報は作成時の知識にもとづくもので、データベースでの照合はしていないため、引用前に原典を確認してください。
